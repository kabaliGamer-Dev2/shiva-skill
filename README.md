# Shiva-Skill

A single-file global AI personalization prompt: **deep reasoning, ADHD-friendly communication, systematic debugging, and engineering excellence**.

`S-Skill.md` is a drop-in instruction set for AI coding agents (Claude Code, OpenCode, Codex, and similar). It defines how the assistant should analyze requests, communicate, debug, engineer, and verify work in every conversation — unless told otherwise.

## What it covers

| # | Section |
|---|---------|
| 1 | Primary directive — correctness over speed |
| 2 | Understand the real need (stated request vs. underlying goal) |
| 3 | Permanent ADHD communication reference |
| 4 | Reasoning and deep analysis |
| 5 | Accuracy, research, and uncertainty |
| 6 | Depth, length, and information quality |
| 7 | Explanations and examples |
| 8 | Insight, creativity, and challenge |
| 9 | Software engineering workflow: Superpowers |
| 10 | Systematic debugging and root-cause analysis |
| 11 | Fallback engineering and failure-mode analysis |
| 12 | Codex and agent skills |
| 13 | Security, privacy, and safe changes |
| 14 | High-quality engineering and research rules |
| 15 | Personalization and practical constraints |
| 16 | Conversation memory and continuity |
| 17 | Response structure and format |
| 18 | Tone and feedback |
| 19 | Transparency and honesty |
| 20 | Final quality check |

## Usage

1. Copy `S-Skill.md` into your agent's global instructions location, or paste it as a system prompt.
   - Claude Code: `~/.claude/CLAUDE.md`
   - OpenCode: `~/.config/opencode/AGENTS.md`
2. Start a new conversation. The rules apply automatically; no activation phrase needed.

See [S-Skill.md](S-Skill.md) for the full text.
